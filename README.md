# 安全笔记 · 使用说明

> 三种笔记，各管一件事：**writeup 记「怎么打」，踩坑记「为什么卡」，速查卡记「怎么用」**。
> 目标：三个月后不用翻书，打开这里就能复现、能讲、能查。

## 目录

```
security-notes/
├── README.md                 ← 你在这
├── writeups/                 ← ① 操作记录：每打一个模块一篇
│   └── 01-DVWA-SQL注入-Low.md
├── pitfalls/                 ← ② 踩坑记录：报错 → 原因 → 解法
│   └── 踩坑记录.md
└── cheatsheets/              ← ③ 速查卡片：命令、payload、用法
    └── 速查卡片.md
```

## 三种笔记怎么用

| 类型 | 什么时候写 | 写多长 | 有什么用 |
|---|---|---|---|
| writeup | 打完一个模块 | 20–40 分钟 | 面试讲项目、复现、证明你真干过 |
| 踩坑 | 卡住并解决之后 | 3–5 分钟 | 下次遇到同样问题 30 秒解决 |
| 速查卡 | 用到新命令/工具时 | 1–2 分钟 | 不用翻书、不用搜 |

## 使用习惯

1. **打靶别边打边记**，打完再写。
2. **每篇笔记必须能独立看懂**：三个月后的你，就是读者。
3. **每周日 15 分钟复盘**：翻一遍，把能变成「面试一问一答」的点挑出来。
4. **不追求全**，追求「用的时候查得到」。

## 下次开机清单（Kali）

```bash
# 1. 启动数据库
sudo systemctl start mariadb

# 2. 启动 DVWA（目录按实际位置）
cd /opt/dvwa && sudo php -d auto_prepend_file=/opt/dvwa/prepend.php -S 0.0.0.0:8080

# 3. 浏览器
# http://127.0.0.1:8080  → admin / password
```

> `/tmp` 会被系统定期清理，DVWA 建议放 `/opt/dvwa`，不要长期放 `/tmp`。

## 安全纪律

所有操作只在自己的靶场、或**有书面授权**的目标上进行。
未经授权测试真实系统，可能触犯《刑法》第 285、286 条与《网络安全法》。
