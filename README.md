# 安全笔记

> 三种笔记，各管一件事：**writeup 记「怎么打」，踩坑记「为什么卡」，速查卡记「怎么用」**。
> 目标：三个月后不用翻书，打开这里就能复现、能讲、能查。

## 目录

```
security-notes/
├── README.md                     ← 你在这
├── writeups/                     ← ① 操作记录（按难度分目录）
│   ├── README.md                 ← 按难度索引
│   ├── _模板.md                  ← 新 writeup 从这里抄
│   ├── 简单/   （15 篇）
│   ├── 中等/   （5 篇）
│   └── 困难/   （3 篇）
├── pitfalls/                     ← ② 踩坑记录
│   └── 踩坑记录.md
└── cheatsheets/                  ← ③ 速查卡片
    ├── 速查卡片.md               ← 源文件（手改这个）
    └── 速查卡片.docx             ← Word 版（脚本生成，别手改）
```

## writeup 写作标准（四问）

每篇必须回答清楚这四件事，否则不算完成：

| 问题 | 写在 |
|---|---|
| **每一步为什么这么做** | 推理链（假设 → 验证 → 结论） |
| **代码/载荷从哪来** | 来源与构造过程 |
| **代码在干什么** | 逐段解释，禁止「顾名思义」 |
| **为什么这样能成功** | 成功条件 vs 失败条件对照 |

另外两节必写：

- **失败尝试**：走过的弯路、为什么失败（避免重走）
- **复盘自测**：3 道带答案的题，答不上就回读

模板：[`writeups/_模板.md`](writeups/_模板.md)

## 三种笔记怎么用

| 类型 | 什么时候写 | 写多长 | 有什么用 |
|---|---|---|---|
| writeup | 打完一题 | 20–40 分钟 | 面试讲项目、复现、证明你真干过 |
| 踩坑 | 卡住并解决之后 | 3–5 分钟 | 下次遇到同样问题 30 秒解决 |
| 速查卡 | 用到新命令/工具时 | 1–2 分钟 | 不用翻书、不用搜 |

## 使用习惯

1. **打靶别边打边记**，打完再写。
2. **每篇笔记必须能独立看懂**：三个月后的你，就是读者。
3. **每周日 15 分钟复盘**：翻一遍，把能变成「面试一问一答」的点挑出来。
4. **不追求全**，追求「用的时候查得到」。

## 下次开机清单（Kali）

```bash
# 1. 启动数据库
sudo systemctl start mariadb

# 2. 启动 DVWA（目录按实际位置）
cd /opt/dvwa && sudo php -d auto_prepend_file=/opt/dvwa/prepend.php -S 0.0.0.0:8080

# 3. 浏览器
# http://127.0.0.1:8080  → admin / password
```

> `/tmp` 会被系统定期清理，DVWA 建议放 `/opt/dvwa`，不要长期放 `/tmp`。
