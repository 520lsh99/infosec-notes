> 环境：Kali + 浏览器
> 日期：2026-11-21

---

## 一、目标

页面干净，但 HTML 注释里藏着 PHP 判断逻辑，满足条件即可拿 flag。

## 二、复现

### 2.1 看源码

打开靶机首页，按 `Ctrl + U`。在 HTML 底部注释里找到：

```php
<!--
$cat=$_GET['cat'];
echo $cat;
if($cat=='dog'){
    echo 'Syc{cat_cat_cat_cat}';
}
-->
```

### 2.2 带参数访问

```
http://靶机/?cat=dog
```

页面回显 `dog`，随后输出 flag。

最终提交：

```
CTF2{b4e4ec9a-d2c6-4f35-b565-57e468adde3b}
```

## 三、原理

| 点 | 说明 |
|---|---|
| `$_GET['cat']` | 从 URL 取 `cat` 参数 |
| 注释泄露逻辑 | 开发者把判断条件留在 HTML 注释里 |
| 弱比较 `==` | 本例是简单字符串比较 |

## 四、扩展：PHP 弱类型比较

如果遇到 `==` 且两侧类型不同，可以尝试：

``` 
?cat=0            # "0" == 0
?cat=1e1          # "1e1" == 10（科学计数法）
?cat[]=1          # 传数组，类型不同
?cat=dog%00       # 截断（老版本）
```

本题只需正常字符串 `dog`。

## 五、修复

- 不要把业务逻辑（尤其是判断条件）写进前端注释
- 用严格比较 `===`
- 不要在注释里留测试代码

## 六、踩坑

- 参数名是 `cat`，不是 `dog`（容易看反）
- 源码在 HTML 末尾，别只看开头

## 七、收获

- 养成「先看源码」的习惯：注释、调试代码、隐藏参数经常直接给答案。
- 记住 PHP 弱比较的几种常见绕过形态。
